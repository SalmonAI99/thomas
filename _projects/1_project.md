Cirdan explores how coding agents can diagnose and debug distributed systems. I built an agent for this setting and designed benchmarks to evaluate LLM debugging capabilities.

The work studies how agent harness design and evaluation methodology affect debugging performance. Its research outcome, **DistDebug-Bench: Can LLM Agents Diagnose Bugs in Distributed Systems?**, was accepted to the NeurIPS 2026 Evaluations and Datasets Track as a poster.
